Mini Racer sprite sources

- `audi-r8.png`, `audi-r8-black.png`, `lamborghini-gallardo.png`: copied from the public GitHub repo `jjimenezg93/SuperCars` (`Resources/` folder) which includes top-down real car sprites used in the racing sample project.
- `dodge-viper.png`, `traffic-audi-red.png`, `traffic-police.png`, `traffic-taxi.png`, `traffic-hatchback.png`, `traffic-minivan.png`, `traffic-pickup.png`: copied from the existing `public/assets/arcade/river-crossing/unlucky` vehicle sprite set already attributed to Unlucky Studio / OpenGameArt in the River Crossing pack.

Notes

- These files are local copies curated for the standalone `Mini Racer` game so students can pick recognizable supercars while keeping the project self-contained.
