River Crossing sprite sources

- `unlucky/*.png`: Unlucky Studio top-down vehicle sprite pack downloaded from OpenGameArt file URL `https://lpc.opengameart.org/sites/default/files/Topdown_vehicle_sprites_pack_Unluckystudio.zip`
- `unlucky/vehicle_bus_top.png`: DevilsWorkShop 2D Car Pack top-view bus sprite downloaded from OpenGameArt file URL `https://opengameart.org/sites/default/files/2D_Car_Pack_DevilsWorkShop_V01.zip`
- `vehicle_car_top.svg`: Openclipart, "top view car"
- `vehicle_convertible_top.svg`: Openclipart, "car top view"
- `vehicle_racer_top.svg`: Openclipart, "dark blue racing car top view"
- `vehicle_sedan_top.svg`: Openclipart, "black car topview"
- `vehicle_bus_top.svg`: Openclipart, "bus"
- `vehicle_taxi_top.svg`: local sprite copy derived from `vehicle_car_top.svg`
- `vehicle_sports_top.svg`: local sprite copy derived from `vehicle_racer_top.svg`
- `vehicle_police_top.svg`: local sprite copy derived from `vehicle_sedan_top.svg`
- `vehicle_ambulance_top.svg`: local sprite copy derived from `vehicle_car_top.svg`
- `vehicle_pickup_top.svg`: local sprite copy derived from `vehicle_convertible_top.svg`
- `vehicle_citybus_top.svg`: local sprite copy derived from `vehicle_bus_top.svg`
- `vehicle_schoolbus_top.svg`: local sprite copy derived from `vehicle_bus_top.svg`

Notes

- Frog sprites are local project SVGs created for this arcade suite.
- The River Crossing road cars now primarily use the downloaded Unlucky Studio PNG sprites for Audi, taxi, police, ambulance, mini truck, minivan, truck, and sports car.
- The River Crossing buses now use the downloaded DevilsWorkShop top-view bus sprite, with small route badges added at runtime for city and school variants.
