CHROMEBOOK / LAN ACCESS

Any device on the same Wi-Fi can open these URLs to play:

Make sure the server PC's firewall allows port 3000. Students on Chromebooks just open the URL in Chrome — no install needed.

1

Same Wi-Fi
Make sure the teacher's PC and all Chromebooks are on the same school Wi-Fi network.

2

Open Chrome
On the Chromebook, open Chrome and type (or tap) the LAN URL shown above into the address bar.

3

Pick a Game
The Arcade page loads instantly — click any game to start playing right away, no sign-in needed.

4

Firewall?
If it doesn't connect, open Windows Defender Firewall and allow Node.js on port 3000 for private networks.
